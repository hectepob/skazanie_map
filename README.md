# Сказание — интерактивная карта мира

Интерактивная карта мира онлайн-игры **«Сказание»**.

Сайт проекта:
**https://hectepob.github.io/skazanie_map/**

## О проекте

Этот проект представляет собой интерактивную карту игрового мира «Сказание», позволяющую быстро находить нужные локации и получать информацию о содержимом клеток карты.

Карта предназначена для удобной навигации по игровому миру и содержит информацию о регионах, областях, монстрах, NPC, предметах, зданиях, переходах между этажами и других игровых объектах.

## Возможности

* интерактивная карта мира;
* поиск по номеру клетки;
* поиск монстров;
* поиск NPC;
* поиск предметов;
* поиск зданий;
* переход между регионами и подзонами;
* отображение этажей;
* масштабирование карты;
* калькулятор характеристик монстров;
* отображение информации о выбранной клетке.

## Для кого

Проект будет полезен игрокам онлайн-игры **«Сказание»**, которым требуется быстро найти:

* нужную локацию;
* монстра;
* NPC;
* предмет;
* здание;
* игровой регион или подзону.
